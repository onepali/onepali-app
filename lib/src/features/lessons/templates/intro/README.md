# Intro Template

- Type: `intro`
- View: `lib/src/features/lessons/templates/intro/intro_lesson_view.dart`
- Logic: view-driven (no dedicated bloc)

## Variables (`IntroLessonContent`)
- `id`, `index`, `type`
- `bgColor`
- `image`
- `audio`
- `bgImageMobile`, `bgImageTablet`

## UI
- Shows intro media (image/background) with optional intro audio.
