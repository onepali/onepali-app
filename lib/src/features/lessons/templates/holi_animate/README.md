# Holi Animate Template

- Type: `holi_animate`
- View: `lib/src/features/lessons/templates/holi_animate/holi_animate_view.dart`
- Logic: view-driven (no dedicated bloc in lesson page)

## Variables (`HoliAnimateLessonContent`)
- `id`, `index`, `type`
- `audio`
- `bgImage`, `bgImageTb`
- `image`
- `items` (`List<Item>`)

## UI
- Plays Holi-themed animation sequence on background scene.
- Interaction and animation timing are controlled inside the view.
